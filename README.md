# 📊 Sales Analysis Project

## 📌 Overview
This project analyzes sales data to extract meaningful business insights.  
It helps understand revenue trends, category performance, and regional sales distribution using Python-based data analysis and visualization tools.

---

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

---

## 📁 Project Structure
sales-analysis/
│
├── data/ # Raw dataset (CSV files)
├── output/ # Generated charts and reports
├── src/ # Python code
├── sales_clean.csv # Cleaned dataset
├── sales_report.xlsx # Excel report
├── chart.png # Static visualization
├── dashboard.html # Interactive dashboard
└── README.md


---

## 🚀 Features
- Data cleaning and preprocessing
- Revenue analysis by category and region
- Monthly sales trend analysis
- Interactive dashboard using Plotly
- Export results as CSV, Excel, and HTML
